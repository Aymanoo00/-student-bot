# سُكّرة — قالب متجر سلة (React)

قالب واجهة متجر لـ [سلة](https://salla.sa) مبني بـ **TanStack Start** و**Vite**،
ويُعرض من جهة الخادم (SSR) على workerd عبر `@salla.sa/twilight-theme-engine`.

هذا القالب مبني على قالب «رائد» الرسمي (`theme-raed`) مع طبقة هوية بصرية
خاصة بـ **سُكّرة**: لوحة ألوان تركوازية/ذهبية رسمية، خط **IBM Plex Sans Arabic**،
دعم كامل لـ RTL، تجربة **Mobile First**، وشريط إعلانات أعلى الصفحة.

---

## المتطلبات

- **pnpm 10**
- **Node.js 22** (22.22.2 أو أحدث) أو **24** (24.15.0 أو أحدث) أو **26+**

> ملاحظة: تشغيل مجموعة الاختبارات (`pnpm test`) يحتاج Node 22+ لأن بعض
> الاعتماديات (undici 8) تتطلب ذلك.

## التثبيت والتشغيل المحلي

```bash
pnpm install
pnpm dev
```

عند تشغيل `salla theme dev` يُكتب ملف `.env` يحتوي `VITE_STORE_DOMAIN`
(يشير افتراضياً إلى المتجر التجريبي) لتوجيه خادم التطوير إلى بيانات متجرك،
و`VITE_TWILIGHT_URL` وهو إصدار SDK الاحتياطي.

> إن لم تُنشأ روابط `node_modules/.bin` (بيئة بلا `pnpm install` كامل)، يمكنك
> تشغيل الأدوات مباشرة عبر Node، مثال:
> `node node_modules/vite/bin/vite.js build` و
> `node node_modules/typescript/bin/tsc --noEmit`.

## البنية

```text
app/start.ts          وسيط الطلبات (نادراً ما يُعدّل)
app/router.tsx        تسجيل مكوّنات الصفحة الرئيسية والخطافات
app/routes.ts         بيان المسارات المخصّصة
app/routes/__root.tsx ملف الجذر الوحيد المُدار يدوياً
app/components/       مكوّنات القالب وتجاوزاتها
  layout/             الهيدر، الفوتر، شريط الإعلانات، التخطيط، الأشرطة السفلية
  product/            بطاقة المنتج، صفحة المنتج، العرض السريع (QuickView)
  home/               أقسام الصفحة الرئيسية
  cart/               السلة
app/hooks/            خطافات React
app/lib/              مساعدات غير React
app/styles/           Tailwind + SCSS (طبقة الهوية في 04-components/sokarh-brand.scss)
locales/{ar,en}.json  ترجمات القالب
twilight.json         إعدادات التاجر وعناصر الصفحة الرئيسية والمزايا
```

## الصفحات والمكوّنات

- **الهيدر والفوتر**: هيدر مُعاد بناؤه (صفّان: إجراءات/شعار/قائمة + معلومات المتجر)،
  شريط إعلانات متحرك على الجوال، فوتر بوضعين (أعمدة/متمركز) ووضع داكن.
- **الصفحة الرئيسية**: أقسامها الأحد عشر (سلايدر، بانرات، منتجات مميزة،
  تصنيفات، عروض، ماركات، آراء العملاء، مدونة، مزايا المتجر، يوتيوب، مربّعات).
- **بطاقات المنتجات**: عمودي/أفقي/صورة كاملة/مصغّر، مع زر مفضلة وزر **عرض سريع**.
- **العرض السريع (Quick View)**: نافذة معاينة المنتج فوق القائمة دون مغادرة الصفحة
  (`app/components/product/QuickView.tsx` + `app/styles/04-components/quick-view.scss`).
- **صفحة التصنيف**: قائمة منتجات مع فلاتر (`SallaFilters`)، تبديل شبكة/قائمة، ترتيب.
- **صفحة المنتج**: معرض، تفاصيل، خيارات، نموذج إضافة للسلة، تقييمات، منتجات مشابهة.
- **السلة، البحث، الحساب، المفضلة، الطلبات، المحتوى والسياسات**: مسارات المحرك
  (`search`، `wishlist`، `orders`، `profile`، `wallet`، `notifications`،
  `$slug.c$id` للتصنيف، `$slug.page-$id` للمحتوى/السياسات) مع تنسيق القالب.

## التخصيص

- **إعدادات التاجر**: تُعرّف في `twilight.json` (الألوان، الهيدر، الفوتر،
  عناصر الصفحة الرئيسية، شريط الإعلانات، شكل بطاقة المنتج...).
- **الترجمات**: أضف المفاتيح إلى `locales/ar.json` و`locales/en.json` معاً.
- **الأنماط**: طبقة الهوية في `app/styles/04-components/sokarh-brand.scss`.

## الربط بحساب مطوّر سلة

1. أنشئ حساب مطوّر على [Salla Partners](https://salla.partners).
2. ثبّت أداة سلة: `npx @salla.sa/cli@beta theme create` (أو استخدم هذا المجلد مباشرة).
3. اربط المجلد بمتجرك التجريبي عبر `salla theme dev`، ثم اكتب `.env` تلقائياً.
4. لرفع القالب: ادفعه إلى مستودع Git الخاص بك، وتتولّى منصة سلة البناء والنشر.
   لا يحتاج القالب أي إعداد نشر أو بيانات اعتماد.
